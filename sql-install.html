Sistema completo de persistencia con funciones SECURITY DEFINER, verificación de email con código OTP y motor de IA conectado directamente a tu base de datos.

¿Qué consigues con esta migración?

Persistencia garantizada. Tus cambios se guardan en base de datos sin depender de servicios externos.
Verificación por código. Sistema OTP propio que envía códigos de 6 dígitos al email del usuario.
IA conectada a tu negocio. El AI Studio ahora consulta directamente tus ventas, productos y márgenes.

Esta migración añade 9 funciones RPC con seguridad SECURITY DEFINER que el frontend puede llamar directamente. No necesitas desplegar Edge Functions ni mantener servicios externos.

Instrucciones de instalación 3 MINUTOS

1

Abre el editor SQL de Supabase

En tu proyecto Supabase, ve a SQL Editor desde el menú lateral izquierdo.

2

Copia el contenido del archivo SQL #49

Descarga el archivo abajo. Tiene ~24 KB con 9 funciones y sus permisos.

3

Pega y ejecuta

Pega el contenido en el editor y pulsa Run. La operación es idempotente: si ya estaba aplicado, simplemente se actualiza.

4

Verifica el mensaje final

Al final del log deberías ver un mensaje MOZONA TPV — SQL #49 APLICADO con el conteo de funciones y tablas creadas.

Importante: Esta migración es independiente del resto. Si tienes aplicados SQL #43, #44, #45, #46 y #48, esta se añade limpiamente sobre ellos. Si no, este SQL es autocontenido y crea todo lo necesario.
⚠️ Paso adicional crítico en Supabase (Authentication):

Para que el registro funcione sin enviar emails (no tienes SMTP configurado), ve a:
Authentication → Providers → Email → Confirm email
y DESACTÍVALO.

Sin esto, Supabase exigirá confirmación de email y los nuevos usuarios no podrán iniciar sesión aunque hayan introducido bien la contraseña.

🚀 Configuración de Resend (3 minutos)

Por qué Resend: Plan gratuito = 100 emails/día, sin tarjeta de crédito, entrega profesional sin marcas de agua.
1

Crea cuenta gratuita en Resend

Ve a https://resend.com/signup y registra tu cuenta con el email rofixinsta@gmail.com.

2

Obtén tu API Key

En el dashboard de Resend → API Keys → Create API Key. Copia la clave (empieza por re_...).

3

Configura el Secret en Supabase Edge Functions

Ve a Supabase → Edge Functions → Manage Secrets. Añade:

RESEND_API_KEY = tu clave de Resend
RESEND_FROM_EMAIL = onboarding@resend.dev (dominio de prueba) o tu dominio verificado

4

Despliega la Edge Function

Ve a Edge Functions → New function → nombre: send-email. Pega el código Deno del archivo SQL #52 (sección 6 del archivo).

5

Programa el cron (opcional)

Para que los emails se envíen automáticamente cada minuto, en Supabase SQL Editor ejecuta:

SELECT cron.schedule('send-emails', '* * * * *', $$ ... $$);

(El código exacto está en SQL #52 sección 6.)

Mientras tanto: La Edge Function se puede invocar manualmente desde cualquier cliente via:
supabase.functions.invoke('send-email', { body: {} })
El frontend ya hace esto automáticamente tras generar el código OTP.
